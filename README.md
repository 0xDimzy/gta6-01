An open-world crime game in the spirit of GTA 6, playable in a desktop browser from static files with no network request. A sun-soaked modern city to explore on foot and by car, with traffic and pedestrians, cars to steal, a wanted level and police, missions and a story, combat, a HUD with a minimap, a start screen and a save.

Built for the [make.fun gta6-01 bounty](https://make.fun/bounty/gta6-01).

Serve it locally with `node serve.ts`, then open http://localhost:8080.
